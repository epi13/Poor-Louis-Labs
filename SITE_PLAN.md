# Site plan

## Purpose

Replace the former modal-based brochure with a serious, addressable public record of the Poor Louis Labs project network.

## Routes

- `/` — orientation, flagship MNCS treatment, programs, selected work, principles, farm relationship.
- `/projects/` — complete public repository catalog with progressive filtering.
- `/projects/[slug]/` — generated project records.
- `/mncs/` — flagship standards and ecosystem page.
- `/research/` — research-focused subset.
- `/notes/` — preserved and future technical writing.
- `/about/` — identity, publication boundary, and farm relationship.
- `/404.html` — static error page.

## Editorial model

Projects are grouped by purpose, labeled by maturity, and given limitations when interpretation requires them. Repository existence alone is not treated as evidence of production readiness.
