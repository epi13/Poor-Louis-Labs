# Design system

The design uses a warm neutral paper field, graphite typography, muted steel-blue accents, square borders, and editorial spacing. Georgia provides restrained display typography; the system sans stack handles interface and body text; monospace is limited to status and technical metadata.

The system intentionally avoids glassmorphism, neon gradients, aurora imagery, star fields, fake terminals, decorative dashboards, and modal navigation. Alaska appears as factual context rather than themed decoration.

Layouts collapse to one column below 820px. Focus remains browser-visible, navigation uses real links, filters are optional progressive enhancement, and reduced-motion preferences disable smooth scrolling.
